# 「さ」— フォロワー向けAI解説コンテンツ生成スキル

読者は「AIに興味はあるが専門家ではない人」。
トーンはカジュアル（語りかけ口調。言葉選びで親しみやすさを出す）。
すごさが伝わる具体例（金額・時間・「文庫本◯冊ぶん」等の体感表現）を必ず入れる。

## 記号ルール（重要・全パート共通）

読者がそのまま投稿・コピーする文章では、次の記号を使わない:
- ダブルクオート " ” と、強調のアスタリスク * ＊ と、ハッシュ # ＃
- 絵文字（🥹🫶🔥💾等、すべての絵文字）
- 強調したいときは太字（**）にせず、言葉選びや語順で目立たせる
- 引用・強調で囲みたいときは日本語の「」や『』を使う
- ハッシュタグは付けない（# を使わないため）
- カジュアルさは絵文字ではなく語尾や口調（〜だよ／〜かも／〜だよね等）で出す

この禁止は「読者に見せる本文」（3行まとめ・X投稿・note本文・プロンプト集の中身）に適用する。
このSKILL.md自体や、裏取りメモの見出し・チャットのダイジェスト整理には
markdown記号や絵文字を使ってよい（読者に見せる本文ではないため）。

## STEP 1. トピック選定（優先順位つき・新しさ最優先）

- 引数あり（例: `さ Gemini`）→ そのトピックを調査対象にする
- 引数なし → 下の「選定の優先順位」に従って 1〜2トピックを自動選定する
  （多くても3つまで。全部盛りにしない）
- どの階層でも新しさが最優先。原則として発表・公開が数時間前〜1日前（24時間以内）の
  ものを取り上げる。見つからない場合のみ直近2〜3日まで許容。1週間以上前のネタは避ける
- 検索は今日の日付を必ず確認してから行う

### 選定の優先順位（上から順に探し、見つかった階層で決める）

**第1優先：主要AI企業の公式HP・公式発表**
下の一覧の企業・サービスについて、公式サイトや公式ブログの「最近の正式発表」
（新モデル・新機能・新サービス・重要アップデート）を最優先で探す。
検索例:「(企業名) blog」「(サービス名) announcement <今月>」「(企業名) newsroom」。
可能なら WebFetch で公式ページを直接確認し、一次情報として裏取りする。

| AI / サービス | 開発会社 |
|---|---|
| Claude（Claude Code含む） | Anthropic（anthropic.com / claude.com） |
| ChatGPT / GPT | OpenAI（openai.com） |
| Gemini | Google（DeepMind）（blog.google / deepmind.google） |
| Copilot | Microsoft（OpenAIの技術を活用）（blogs.microsoft.com） |
| Grok | xAI（イーロン・マスク）（x.ai） |
| Llama | Meta（ai.meta.com） |
| DeepSeek | DeepSeek（中国）（deepseek.com） |

| Perplexity | Perplexity AI（perplexity.ai） |
| Mistral | Mistral AI（フランス）（mistral.ai） |

**第2優先：日本で起きたAI関連の新しいニュース**
第1優先で24時間以内の適当な公式発表が見つからない場合は、日本国内のAIニュースを探す。
Yahoo!ニュース・ITmedia・PC Watch・Impress・日経等は「○時間前」表記が出るので、
それを見て新しい順に選ぶ。検索例:「AIニュース <今日の日付>」「AI 発表 日本 <今月>」

**第3優先：世界で広く読まれているAI関連ニュース**
第1・第2でも見つからない場合は、海外の主要メディア（TechCrunch・The Verge・CNBC・
Bloomberg等）で広く報じられているAIニュースを取り上げる。検索例:「AI news today」

- 迷ったら「○時間前」がより小さい（＝より新しい）ものを優先する
- どの階層を採用したかは、チャットのダイジェストで一言触れる
  （例:「今回は第2優先の日本ニュースから選定」）

## STEP 2. 裏取り（最重要）

- **公式発表**（各社ブログ・公式ドキュメント）と**信頼できる報道**（TechCrunch、
  CNBC、The Verge 等）を WebSearch / WebFetch で確認する
- **✅事実**（公式・複数報道で確認）と **🔍未確定**（報道・予告レベル）を必ず分ける。
  🔍は「〜と報じられている」と書く。断定しない
- 使った**参考リンクを全部残す**（成果物に URL 一覧として入れる）
- Claude / Anthropic のモデル仕様・料金に触れる場合は、記憶で書かず
  `claude-api` スキルの情報（またはplatform.claude.comの公式ドキュメント）を優先する

## STEP 3. 「結局なにがすごいのか」3行

トピックごとに、**専門用語ゼロ**で3行にまとめる。
- 1行目: 一番のインパクト（生活・仕事がどう変わるか）
- 2行目: 意外性・ドラマ（数字や事件性があれば使う）
- 3行目: 読者が今日できること・体感できる例

## STEP 4. X用140字投稿（トピックごとに1本）

- **各トピックにつき1本**、**135〜145字**で生成し、コピペできるようコードブロックで出す
- 構成: フック（1文目で驚かせる）→ 事実 → ひとこと所感 or 行動喚起
- ハッシュタグは付けない。絵文字・ダブルクオート・アスタリスクも使わない
- 🔍未確定情報をXに載せる場合は「〜らしい」「報道によると」を必ず入れる
- 文字数を数えて調整すること（URL を入れる場合は本文と別行に）

## STEP 5. note記事用パッケージ

文字数は「伝わるなら何文字でもいい」。以下を作る:

### (a) 解説記事の構成案（タイトル案3つ付き）
- タイトル案3つ: ①事件・ドラマ型 ②読者への語りかけ型 ③保存版・まとめ型 の3方向で
- 構成: 導入（つかみ）→ トピック解説（1トピック=事実→すごさ→具体例→読者メリット）
  → 「で、何を使えばいい？」の使い分け → プロンプト集（保存誘発）→ CTA

### (b) コピペで試せる実用プロンプト集
- **5本以上**。トピックに関連するAIで実際に試せるもの
- 各プロンプトは「●●だけ自分のものに変えてね」形式で、貼るだけで動く完成文にする
- 遊べる系（SNSネタになるもの）を1本以上入れる

## STEP 6. 出力

1. 全成果物を1つのMarkdownファイルにまとめ、scratchpadに保存して
   `SendUserFile`（display: render）で届ける
   - ファイル構成: PART 0 裏取りメモ（✅/🔍＋参考リンク）→ PART 1 3行まとめ
     → PART 2 X用140字投稿 → PART 3 note構成案＋タイトル案 → PART 4 プロンプト集
     → 末尾に「発信時の注意メモ」（🔍情報の扱い・日付や価格の再確認）
2. チャットにはダイジェストを出す: 選んだトピックとその理由 → 3行まとめ →
   **X投稿はチャットにも全文貼る**（すぐコピーできるように）→ タイトル案 → 参考リンク

## 禁止・注意

- 裏取りなしで書かない。検索結果が古い可能性を常に疑い、日付を確認する
- 憶測を事実のように書かない（🔍ラベル必須）
- 専門用語を使う場合は（）で一言解説を添える
- 他人・他社を貶める切り口にしない（「終了」等の事実は書いてよいが煽らない）
